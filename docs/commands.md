# Slash Command Reference

| Command | Scope | Description | Usage | Examples |
|---------|-------|-------------|-------|----------|
| /contest | Global | Manage photo contests on this server. | /contest create | Use /contest create to launch a new themed contest. |
| /ping | Global | Check whether the bot is online and measure websocket latency. | /ping | Use /ping before a contest starts to ensure the bot is ready. |
